# COE Management Portal

A Controller of Examinations (COE) administration portal built with React 19, TypeScript, Vite, and Tailwind CSS v4.

## Features

- **Exam Scheduling**: Create, edit, and manage IA (Internal Assessment) and SEE (Semester End Examination) schedules.
- **Package Export**: Export standardized JSON packages for exam centers.
- **File Transfer & Checklist**: Track secure manual delivery checklists and import verified student result files.
- **Key Approvals**: Review and approve/reject HOD answer key correction requests with real-time mark impact re-calculation.
- **Results Management**: View student mark distributions, calculate statistics, and handle versioned publications.
- **Activity Audit Log**: Full chronological trail of all exam actions, transfers, approvals, and publications.

## Tech Stack

- **Framework**: React 19
- **Routing**: React Router v7
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Build Tool**: Vite 8
- **Language**: TypeScript

## Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or pnpm

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Build

```bash
npm run build
```
